TravelTalk V2.0 Beta — 前端连续字幕实验版

重要：本包不是云端流式ASR，不承诺电影连续对白完整识别。仍使用 iOS Safari SpeechRecognition 与 V1.5 免费翻译服务。

已实现：
- 连续识别事件按段写入历史；历史最多200条
- 识别中间结果延迟450毫秒尝试中文预览；不等待整句最终确认
- 最终文本翻译异步排队（最多2个并发），每条记录独立更新，避免错位覆盖
- 浏览历史、输入中文、60秒整理时不主动停止监听；只有播放语音时临时停止以避免自我收音
- 每60秒摘录已翻译内容，保留原文和中文记录
- 显示识别、翻译排队、重连状态
- 切回前台时尝试恢复，不能突破iOS后台限制

尚未实现：
- 真正的连续音频上传与流式ASR；需要后端服务和安全的密钥管理
- AI语义归纳与真正的上下文回复（目前仅固定应急回复）
- 可证明的漏音检测、说话人分离和嘈杂环境降噪
- iPhone真机性能测试

部署：解压后将本文件夹内 index.html、translation-v15.js、manifest.webmanifest、sw.js、README.txt 五个文件上传到 GitHub 仓库根目录，覆盖同名文件。旧版 recovery.js、context-replies.js 可以暂时保留但本版不引用。GitHub Pages 更新后重新打开或移除旧主屏幕快捷方式再添加。

警告：免费翻译接口可能不稳定；不要把本测试版用于过敏原等重要信息的唯一判断依据。
